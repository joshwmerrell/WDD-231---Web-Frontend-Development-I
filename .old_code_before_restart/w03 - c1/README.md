# Yellowstone Field Notes starter

This starter keeps the hike entries as HTML in `index.html`. The difficulty
control is present, but hike data loading, rendering, and filtering have not
been implemented. The only JavaScript in the starter controls the mobile
navigation. It reuses `../styles.css` from the complete demo.

From the repository root, serve the files over HTTP:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000/demos/yellowstone-guide/start/>.
